# XIV Studio
### Space for sound. Tools for ideas.

A small, interactive studio booking playground by [XIVWorld](https://github.com/XIVWorld).

**Fictional data · No payments · No live bookings**

</div>

---

## Explore the project

Choose a sample session, adjust its length, compare a quote, and simulate a booking. Reset instantly and experiment again.

This is a standalone public concept, built for people to explore and extend. It is not the operational studio booking app. Rates and availability are illustrative.

## Try it locally

Download this repository and open `index.html` in a modern browser. No installation, account, API keys or environment variables are needed.

## How it works

| File | Purpose |
| --- | --- |
| `index.html` | Responsive interface, fictional session rates and in-memory interactions |
| `DEMO-BOUNDARIES.md` | Isolation design and deployment review |
| `PROFILE-README.md` | Proposed introduction for the XIVWorld GitHub profile |

Everything runs in browser memory. A restrictive Content Security Policy blocks network connections, external assets and form submissions. Reset or reload clears the experience.

## Build on it

Fork the repository, edit the HTML/CSS/JavaScript, and open the page again. Improvements to accessibility, visual design and the local simulation are welcome through pull requests.

The newly authored demo code is MIT licensed; see `LICENSE`. No private application source, recordings, customer data or production integrations are included.

## Publishing status

The proposed demo is awaiting review and deployment approval. There is no hosted demo URL yet. Any future deployment must serve only this standalone static artifact and use no production credentials or integrations.
